# Security Policy

Pixie runs an AI agent against user-selected workspaces. Please report security
issues privately instead of opening a public issue.

## Reporting

Email security reports to the maintainers, or use GitHub's private vulnerability
reporting if it is enabled for the repository.

Please include:

- Affected Pixie version or commit
- Platform and build type
- Reproduction steps
- Impact and any suggested mitigation

## Scope

High-priority reports include ways for the agent or app to read or modify files
outside the selected workspace, leak secrets unexpectedly, bypass configured
network/API settings, or execute unintended commands.
